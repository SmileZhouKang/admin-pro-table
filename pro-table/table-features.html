附加列配置 ​

序号列、多选列、操作列的配置说明。

数据列配置见 列配置，请求 / 删除 / 分页 / 工具栏等见 请求与行为配置。

indexColumn — 序号列 ​

属性说明类型默认值
show是否显示序号列Booleantrue
label列头文案String'序号'
width列宽Number60
align对齐方式String'center'
indexMethod自定义序号：(index, page, pageSize) => numberFunction-
js
indexColumn: { show: true, label: 'No.', width: 70 }
// 或自定义序号
// indexColumn: { indexMethod: (i, page, size) => (page - 1) * size + i + 1 }

selection — 多选列 ​

属性说明类型默认值
show是否显示多选列Booleanfalse
width列宽Number55
selectable控制某行是否可勾选：(row) => booleanFunction-

跨页保留勾选需同时配置 tableConfig.rowKey。

禁用状态的行不可勾选；点击「获取选中行」展示当前已选数据。
js
const tableConfig = {
  rowKey: 'id',
  selection: {
    show: true,
    selectable: (row) => row.status === 1  // 禁用行不可选
  },
  // ...
}

// 获取选中行
const rows = tableRef.value?.getSelectedRows()

operationConfig — 操作列 ​

操作列默认显示「编辑」和「删除」按钮，「复制」按钮默认关闭，需要时显式开启。

属性说明类型默认值
show是否显示整个操作列Booleantrue
label操作列标题String'操作'
showEdit是否显示「编辑」按钮；支持 (row) => boolean 按行控制Boolean | Functiontrue
showDelete是否显示「删除」按钮；支持 (row) => boolean 按行控制Boolean | Functiontrue
showCopy是否显示「复制」按钮；支持 (row) => boolean 按行控制Boolean | Functionfalse
width操作列宽度（px）Number100
fixed固定列：'left' / 'right'String'right'
align对齐方式：'left' / 'center' / 'right'String'right'
size按钮尺寸：'large'、'default'、'small'String'small'
columnProps透传给操作列 el-table-column 的属性，如 showOverflowTooltip、resizableObject{}
editPermission「编辑」按钮权限码；支持 (row) => string | string[] 按行返回String | String[] | Function-
deletePermission「删除」按钮权限码；同上String | String[] | Function-
copyPermission「复制」按钮权限码；同上String | String[] | Function-
状态为「待审核」时不显示编辑按钮；管理员角色不显示删除按钮；通过 operation-before/after 插槽扩展「查看」和「审核」按钮。
js
operationConfig: {
  label: '操作栏',
  showEdit: (row) => row.status !== 2,       // 待审核不显示编辑
  showDelete: (row) => row.role !== 'admin', // 管理员不显示删除
  width: 180,
  fixed: 'right',
  align: 'right',
  columnProps: {
    showOverflowTooltip: false
  }
}
vue
<pro-table :table-config="tableConfig">
  <template #operation-before="{ row, tableRef }">
    <el-button link type="primary" size="small" @click="handleView(row)">查看</el-button>
  </template>
  <template #operation-after="{ row, tableRef }">
    <el-button v-if="row.status === 0" link type="warning" size="small" @click="tableRef.openEdit(row)">审核</el-button>
  </template>
</pro-table>

权限码用法详见 按钮权限。未配置全局 hasPermission 或未设置权限码时，仅按 showXxx 控制显隐。

基本用法 ​

js
// 默认：编辑 + 删除，不显示复制
operationConfig: {
  width: 140
}

// 开启复制按钮
operationConfig: {
  showCopy: true,
  width: 180
}

// 只读表格：隐藏整个操作列
operationConfig: { show: false }

按行控制显隐 ​

showEdit、showDelete、showCopy 支持传函数，根据当前行数据动态决定是否显示：

js
operationConfig: {
  // 状态为 2（已发布）时不允许编辑
  showEdit: (row) => row.status !== 2,
  // 仅创建人可删除
  showDelete: (row) => row.isCreator === true,
  // 草稿状态可复制
  showCopy: (row) => row.status === 0,
  width: 200
}

配合权限码 ​

js
// 整表统一权限码
operationConfig: {
  editPermission: 'user:edit',
  deletePermission: 'user:delete',
  copyPermission: 'user:copy'
}

// 按行区分权限码（如仅自己创建的才能编辑）
operationConfig: {
  editPermission: (row) => row.isOwner ? 'user:edit' : '',
  deletePermission: (row) => row.isOwner ? 'user:delete' : ''
}

// 多权限码：有任一即显示
operationConfig: {
  editPermission: ['user:edit', 'admin:edit']
}

自定义插槽扩展操作按钮 ​

操作列提供 operation-before 和 operation-after 插槽，可在内置按钮前后插入自定义按钮：

vue
<pro-table :table-config="tableConfig">
  <!-- 在编辑/删除前插入「查看」按钮 -->
  <template #operation-before="{ row }">
    <el-button link type="primary" size="small" @click="handleView(row)">查看</el-button>
  </template>
  <!-- 在编辑/删除后插入「审核」按钮（按行控制）-->
  <template #operation-after="{ row }">
    <el-button v-if="row.status === 0" link type="warning" size="small" @click="handleAudit(row)">审核</el-button>
  </template>
</pro-table>

主题与尺寸 ​

不同项目可通过 app.use(AdminProTable, options) 配置全局主题色和组件/按钮尺寸，无需在每个页面重复设置。

快速配置 ​

javascript
import { createApp } from 'vue'
import AdminProTable from 'admin-pro-table'
import 'admin-pro-table/dist/style.css'

const app = createApp(App)

app.use(AdminProTable, {
  // 组件尺寸：large | default | small
  size: 'default',

  // 按钮尺寸（可选，默认与 size 一致）
  buttonSize: 'small',

  // 主题色（写入 :root CSS 变量，弹窗/抽屉同样生效）
  theme: {
    primary: '#1677ff',
    success: '#52c41a',
    warning: '#faad14',
    danger: '#ff4d4f',
    info: '#909399'
  }
})

配置项 ​

属性说明类型默认值
size全局组件尺寸，作用于表格、表单控件、分页等'large' | 'default' | 'small'Element Plus 默认
buttonSize内置按钮尺寸（搜索、工具栏、操作列、表单底栏等）'large' | 'default' | 'small'同 size
theme主题色配置，支持简写或 CSS 变量名Object-

theme 写法 ​

简写颜色（推荐）：

javascript
theme: {
  primary: '#1677ff',
  success: '#52c41a',
  warning: '#faad14',
  danger: '#ff4d4f',
  info: '#909399'
}

直接写 CSS 变量（可覆盖更多 Element Plus 变量）：

javascript
theme: {
  '--el-color-primary': '#1677ff',
  '--el-border-radius-base': '6px'
}

安装时会将 theme 写入 document 的 :root，因此 dialog / drawer 等 teleport 到 body 的弹层也会使用同一套主题色。

影响范围 ​

尺寸（size / buttonSize） ​

区域说明
搜索区输入框、下拉框、搜索/重置按钮
工具栏返回、添加、删除及插槽旁内置按钮
表格el-table 行高（通过 tableProps.size 自动合并）
操作列编辑、删除、复制及 operation-before/after 旁按钮
分页底栏刷新按钮
表单弹层表单控件与取消/保存/提交按钮
独立 ProForm同上

主题色（theme） ​

所有使用 Element Plus 语义色的区域均会跟随，例如 type="primary" 按钮、链接按钮、Tag、分页选中等。

单页覆盖 ​

可在 tableConfig、searchConfig、formConfig 上局部覆盖：

javascript
const tableConfig = {
  size: 'small',
  buttonSize: 'small',
  theme: { primary: '#722ed1' }, // 仅影响当前 ProTable 区域（不含 teleport 弹层）
  operationConfig: { size: 'small' },
  toolbarConfig: { size: 'small' }
}

const searchConfig = {
  size: 'small',
  actionsConfig: { size: 'small' }
}

const formConfig = {
  formAttrs: { size: 'small' },
  footer: { size: 'small' }
}

优先级：

text
区域配置（operationConfig / toolbarConfig / footer 等）
  > 当前页面 tableConfig / searchConfig / formConfig
    > app.use 全局配置
      > Element Plus 默认

TIP

若希望弹窗也使用局部 theme，请在 app.use 层统一配置；tableConfig.theme 主要覆盖列表区域的内联样式。

运行时切换主题 ​

若需在应用内动态换肤（如设置页切换主题），可在修改配置后调用 applyDocumentTheme：

javascript
import AdminProTable, { applyDocumentTheme } from 'admin-pro-table'

// 假设 globalOptions 为 app.use 时传入的 reactive 配置对象
globalOptions.theme.primary = '#00b96b'
globalOptions.size = 'small'
globalOptions.buttonSize = 'small'

applyDocumentTheme(globalOptions.theme)

修改 size / buttonSize 后，建议给 pro-table 设置 :key 触发重新挂载，以确保所有内置按钮尺寸立即更新：

vue
<pro-table :key="`${globalOptions.size}-${globalOptions.buttonSize}`" ... />

本地 examples 演示见 主题与尺寸 菜单（/theme-settings）。

与 tableProps.formAttrs 的关系 ​

全局 size 会自动合并进 tableProps 与 formAttrs，无需重复写：

javascript
app.use(AdminProTable, {
  size: 'small',
  tableProps: { border: true, stripe: true }, // 自动带上 size: 'small'
  formConfig: { labelWidth: '100px' }          // formAttrs 自动带上 size: 'small'
})

若显式配置了 tableProps.size 或 formAttrs.size，则以显式值为准。

ProFormPopup 弹层表单 ​

ProFormPopup 是弹窗 / 抽屉 / 整页模式的表单容器，适用于需要手动控制打开关闭的表单场景。

独立页面表单（不需要弹层）使用 ProForm。与 ProTable 联动时由 ProTable 内部自动管理弹层，配置见 表单弹层配置。

基本用法 ​

点击按钮分别以 Dialog 弹窗和 Drawer 抽屉两种模式打开表单，提交后展示数据。
vue
<template>
  <el-button type="primary" @click="open('dialog')">弹窗</el-button>
  <el-button type="success" @click="open('drawer')">抽屉</el-button>
  <ProFormPopup v-model:visible="visible" :config="formConfig" @submit="onSubmit" />
</template>

<script setup>
import { ref, reactive } from 'vue'
const visible = ref(false)
const formConfig = reactive({
  mode: 'dialog',
  width: '480px',
  model: { name: '', status: 1, remark: '' },
  fields: [
    { label: '姓名', key: 'name', component: 'input' },
    { label: '状态', key: 'status', component: 'select',
      options: [{ label: '启用', value: 1 }, { label: '禁用', value: 0 }] },
    { label: '备注', key: 'remark', component: 'textarea', rows: 3, span: 24 }
  ],
  rules: {
    name: [{ required: true, message: '请输入姓名', trigger: 'blur' }]
  },
  add: {
    title: '新增用户',
    api: async (data) => { /* 调用接口 */ }
  }
})
function open(mode) {
  formConfig.mode = mode
  formConfig.formType = 'add'
  visible.value = true
}
function onSubmit(res, formData) { console.log(formData) }
</script>

提交流程与钩子职责 ​

ProFormPopup 的字段处理规则与 ProForm 提交流程 保持一致：日期范围会拆分，展示字段不会提交，nestedKeys 会在提交时展平。

执行顺序：

text
表单校验 → beforeSubmit → 生成提交参数 → filterEmptyParams → add/edit/save.paramsFormat → add/edit/save.api → add/edit/save.responseFormat → afterSubmit → submit/save 事件

paramsFormat 与 beforeSubmit ​

  • beforeSubmit 用于提交前拦截、二次确认或业务校验，返回 false 会取消本次提交。
  • paramsFormat 用于转换最终提交参数，新增 / 编辑 / 保存分别配置在 add.paramsFormat、edit.paramsFormat、save.paramsFormat 中。

responseFormat 与 afterSubmit ​

  • responseFormat 用于转换接口响应，新增 / 编辑 / 保存分别配置在 add.responseFormat、edit.responseFormat、save.responseFormat 中。
  • afterSubmit 用于提交成功后的副作用，例如关闭外部页面、刷新其他数据等。

接口返回对象中包含全局 codeKey 字段时，会先根据全局 successCode 判断成功 / 失败；失败时不会关闭弹层，也不会触发 responseFormat、afterSubmit 和 submit/save 事件。

与 ProTable 配合 ​

当通过 ProTable 的 form-config 使用时，ProTable 内部自动管理 ProFormPopup 的打开、关闭和数据传递，无需手动使用本组件。

完整的 formConfig（add / edit / save / copy）配置说明见 表单弹层配置。

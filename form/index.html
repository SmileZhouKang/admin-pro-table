表单组件 ​

基于 Vue 3 + Element Plus 的配置化表单组件，可与 ProTable 配合使用，也可独立使用。组件统一以 Pro 为前缀导出。

文档结构 ​

页面说明
ProForm 表单独立表单（设置页/详情页）：Props、Config、tabs、Footer、Events、Ref、Slots
ProFormPopup 弹层弹窗 / 抽屉 / 整页表单：弹层专属配置、Footer、Events、Ref、Slots
事件与实例方法ProForm / ProFormPopup 的 Events、暴露方法（Ref）、常见调用方式
字段配置表单项通用属性、支持的 component 类型、联动（visible/disabled、optionsDeps、watchDeps）、插槽示例
上传配置uploadConfig 配置项、字段级覆盖、完整示例
完整示例fetchInitialData、联动、插槽的综合示例

add / edit / save 的完整配置说明在表格文档的 表单弹层配置 中。

快速开始 ​

独立页面表单：

vue
<ProForm :config="formConfig" @submit="onSubmit" />

与 ProTable 联动（弹窗/抽屉/整页）：

vue
<pro-table
  :search-config="searchConfig"
  :table-config="tableConfig"
  :form-config="formConfig"
/>

配置项与字段结构详见 ProForm 表单。

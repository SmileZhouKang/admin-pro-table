表单动作配置（add / edit / save） ​

add / edit / save 的完整配置说明已移至 表单弹层配置，包括：

  • add 配置 — 新增提交的标题、接口、校验规则
  • edit 配置 — 编辑提交的标题、接口、fetchInitialData、idKey
  • save 配置 — 草稿保存的接口、校验规则
  • copy 场景 — 复制走 add 配置
  • 标题优先级 — formConfig.title > add.title / edit.title
  • Footer 配置 — showCancel / showSubmit / showSave

校验优先级速查 ​

场景优先用回退
add（新增）add.rulesformConfig.rules
edit（编辑）edit.rulesformConfig.rules
save（保存）save.rules不回退，不配则不校验
copy（复制）add.rulesformConfig.rules

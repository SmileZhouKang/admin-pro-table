搜索组件 ​

基于 Vue 3 + Element Plus 的配置化搜索表单，用于列表页筛选条件。可与 ProTable 配合使用（通过 search-config），也可独立使用 ProSearchForm。

字段配置与表单字段一致，完整属性见 字段配置。

基本用法 ​

5个搜索项超出1行自动显示展开/收起；类型选中后子类型才可用；点击搜索展示当前条件。
js
const searchConfig = {
  labelWidth: '70px',
  span: 8,
  gutter: 16,
  collapse: true,
  collapsedRows: 1,
  model: { name: '', status: '', type: '', subType: '', date: '' },
  fields: [
    { label: '姓名', key: 'name', component: 'input' },
    { label: '状态', key: 'status', component: 'select',
      options: [{ label: '启用', value: 1 }, { label: '禁用', value: 0 }] },
    { label: '类型', key: 'type', component: 'select',
      options: [{ label: '类型A', value: 'A' }, { label: '类型B', value: 'B' }] },
    { label: '子类型', key: 'subType', component: 'select',
      disabled: (d) => !d.type,
      options: (d) => d.type === 'A'
        ? [{ label: 'A1', value: 'A1' }, { label: 'A2', value: 'A2' }]
        : [{ label: 'B1', value: 'B1' }, { label: 'B2', value: 'B2' }] },
    { label: '日期', key: 'date', component: 'date-picker' }
  ]
}

在 ProTable 中使用 ​

vue
<template>
  <pro-table
    :search-config="searchConfig"
    :table-config="tableConfig"
  />
</template>

<script setup>
import { reactive } from 'vue'

const searchConfig = reactive({
  model: { name: '', status: '' },
  fields: [
    { label: '姓名', key: 'name', component: 'input', placeholder: '请输入姓名' },
    { label: '状态', key: 'status', component: 'select',
      options: [{ label: '启用', value: 1 }, { label: '禁用', value: 0 }] }
  ]
})
</script>

独立使用 ​

vue
<template>
  <ProSearchForm
    :config="searchConfig"
    v-model="searchModel"
    @search="onSearch"
    @reset="onReset"
  />
</template>

<script setup>
import { ref } from 'vue'
import { ProSearchForm } from 'admin-pro-table'

const searchConfig = {
  model: { name: '', status: '' },
  fields: [
    { label: '姓名', key: 'name', component: 'input' },
    { label: '状态', key: 'status', component: 'select', options: [...] }
  ]
}
const searchModel = ref({ ...searchConfig.model })

function onSearch() {
  console.log('搜索', searchModel.value)
}
function onReset() {
  console.log('重置')
}
</script>

Props ​

属性说明类型默认值
config搜索配置对象，见下方 ConfigObject必填
modelValue搜索条件数据（支持 v-model）Object必填

Config 配置 ​

属性说明类型默认值
model搜索项初始值，字段 key 与默认值Object-
labelWidth表单项 label 宽度String'100px'
fields搜索项配置数组，结构同 字段配置Array[]
span每项栅格占位（0–24），可在 field 上单独覆盖；默认 8（一行三个）Number8
gutter栅格间距Number20
collapse是否启用折叠Booleanfalse
collapsedRows折叠时显示的行数Number1
defaultCollapsed默认是否收起Booleanfalse
enterSearch是否开启回车触发搜索Booleantrue
actionsConfig搜索操作区配置，见 actionsConfigObject-

actionsConfig ​

属性说明类型默认值
show是否显示整个操作区Booleantrue
showSearch是否显示搜索按钮Booleantrue
searchText搜索按钮文字String'搜索'
showReset是否显示重置按钮Booleantrue
resetText重置按钮文字String'重置'

折叠说明 ​

  • 启用 collapse: true 后，根据每个字段的 span 在 24 栅格下计算行数
  • 总行数大于 collapsedRows 时，右侧显示「展开」「收起」按钮
  • 收起时只渲染前 collapsedRows 行的字段
  • 可通过 defaultCollapsed 控制初始是展开还是收起

折叠配置示例 ​

js
const searchConfig = reactive({
  model: { name: '', status: '', type: '', subType: '', date: '', region: '' },
  span: 8,              // 一行三个（24 / 8 = 3）
  collapse: true,       // 启用折叠
  collapsedRows: 1,     // 收起时只显示第一行
  defaultCollapsed: true, // 默认收起
  fields: [
    { label: '姓名', key: 'name', component: 'input' },
    { label: '状态', key: 'status', component: 'select',
      options: [{ label: '启用', value: 1 }, { label: '禁用', value: 0 }] },
    { label: '类型', key: 'type', component: 'select',
      options: [{ label: '类型A', value: 'A' }, { label: '类型B', value: 'B' }] },
    // 以下字段在收起时隐藏
    { label: '子类型', key: 'subType', component: 'select',
      options: [{ label: 'S1', value: 'S1' }, { label: 'S2', value: 'S2' }] },
    { label: '日期', key: 'date', component: 'date-picker' },
    { label: '地区', key: 'region', component: 'input' }
  ]
})

上面的配置效果：

  • span: 8 → 一行放 3 个字段
  • 6 个字段 → 2 行
  • collapsedRows: 1 → 收起时只显示第 1 行（前 3 个字段）
  • defaultCollapsed: true → 页面打开时默认收起
  • 右侧自动出现「展开 ↓」按钮，点击后显示全部 6 个字段

不同 span 下的折叠行为 ​

span一行字段数6 个字段共几行collapsedRows=1 时显示
64 个2 行前 4 个
83 个2 行前 3 个
122 个3 行前 2 个
241 个6 行前 1 个

单个字段可通过 field.span 覆盖全局 span，折叠计算会按实际栅格累加。

完整折叠 demo ​

5 个搜索项，span=8（一行三个），超过 1 行自动显示展开/收起按钮；类型选中后子类型才可用。
vue

    :config="searchConfig"
    v-model="searchModel"
    @search="onSearch"
    @reset="onReset"

<script setup>

  gutter: 16,

  defaultCollapsed: false,

    { label: '姓名', key: 'name', component: 'input', placeholder: '请输入姓名' },
    { label: '状态', key: 'status', component: 'select',
      options: [{ label: '启用', value: 1 }, { label: '禁用', value: 0 }] },
    { label: '类型', key: 'type', component: 'select',
      options: [{ label: '类型A', value: 'A' }, { label: '类型B', value: 'B' }] },
    { label: '子类型', key: 'subType', component: 'select',
      disabled: (d) => !d.type,
      options: (d) => d.type === 'A'
        ? [{ label: 'A1', value: 'A1' }, { label: 'A2', value: 'A2' }]
        : [{ label: 'B1', value: 'B1' }, { label: 'B2', value: 'B2' }] },
    { label: '日期', key: 'date', component: 'date-picker', placeholder: '选择日期' }
  ]
})

const searchModel = ref({ ...searchConfig.model })

function onSearch() { console.log('搜索', searchModel.value) }
function onReset() { console.log('重置') }
</script>

Events ​

事件名说明回调参数
update:modelValue搜索条件变更时触发（v-model）(model: Object)
search点击「搜索」时触发-
reset点击「重置」时触发-

Slots ​

插槽名说明作用域参数
[field.slot]某字段配置 slot: 'xxx' 时的自定义控件
extra-[key]字段下方扩展内容（字段 extra: 'slot'）
prepend-[key]控件前插槽（字段 prepend: 'slot'）同上
append-[key]控件后插槽（字段 append: 'slot'）同上

prepend / append 也可直接配置为函数，根据当前搜索条件动态显示辅助内容：

js
fields: [
  {
    label: '金额',
    key: 'amount',
    component: 'input-number',
    prepend: (formData) => formData.currency === 'USD' ? '$' : '¥',
    append: (formData) => formData.currency === 'USD' ? '美元' : '人民币'
  }
]

在 ProTable 中使用时，搜索插槽从 ProTable 透传到 ProSearchForm。建议在字段相关插槽中使用 search- 前缀：

js
fields: [
  { label: '姓名', key: 'name', component: 'input', slot: 'search-custom-name' }
]
vue
<pro-table :search-config="searchConfig">
  <template #search-custom-name="{ modelValue, field, formData }">
    <el-input v-model="formData.name" placeholder="自定义" />
  </template>
  <template #search-append-amount="{ formData }">
    {{ formData.currency === 'USD' ? '美元' : '人民币' }}
  </template>
</pro-table>

更多插槽说明见 插槽总览。

全局配置 ​

在安装时通过 app.use(AdminProTable, { searchConfig: {...} }) 统一配置搜索表单默认值，单表 searchConfig 可覆盖：

js
app.use(AdminProTable, {
  searchConfig: {
    labelWidth: '80px',
    span: 8,
    gutter: 16,
    actionsConfig: {
      show: true,
      showSearch: true,
      showReset: true,
      searchText: '搜索',
      resetText: '重置'
    }
  }
})

字段能力 ​

搜索表单字段支持与表单字段相同的联动能力（visible、disabled、options 函数、watchDeps / onWatchDeps 等），完整说明见 字段配置。

示例：选择类型后才显示子类型搜索项

js
fields: [
  { label: '类型', key: 'type', component: 'select',
    options: [{ label: 'A', value: 'A' }, { label: 'B', value: 'B' }] },
  {
    label: '子类型', key: 'subType', component: 'select',
    visible: (formData) => !!formData.type,
    options: (formData) => formData.type === 'A'
      ? [{ label: 'A1', value: 'A1' }]
      : [{ label: 'B1', value: 'B1' }]
  }
]
